[h1]Reference- Steam Controller Boot Chords/modes[/h1]

The Steam Controller has several operating modes that i can be placed into. Some of them require pressing certain buttons when you either turn on or off the controller. This page helps you find the correct chords (button combos) to enter these modes.

[tr]

[td]Switch To Steam Controller Puck (Right Slot)
[/td]
[td]Off
[/td]
[td]Steam+A+R1
[/td]
[td]2s
[/td]
[td] Steam Controller will switch to the Steam Controller Wireless protocol using the bonding information in the Right slot. This is the default configuration for the controller. After switching you can pair the controller to a Steam Machine or Puck. To pair either plug the Steam Controller into the PC using USB or set the Steam Controller on the Puck while the puck is plugged into the PC. Steam will guide you through the pairing process.
[/td]

[/tr]

[tr]

[td]Switch To Steam Controller Puck (Left Slot)
[/td]
[td]Off
[/td]
[td]Steam+A+L1
[/td]
[td]2s
[/td]
[td]Steam Controller will switch to the Steam Controller Wireless protocol using the bonding information in the Left slot.  After switching you can pair the controller to a Steam Machine or Puck. To pair either plug the Steam Controller into the PC using USB or set the Steam Controller on the Puck while the Puck is plugged into the PC. Steam will guide you through the pairing process.
[/td]

[/tr]

[tr]

[td]Backpack Mode
[/td]
[td]On
[/td]
[td]Steam+L4+L5+R4+R5
[/td]
[td]5s
[/td]
[td]Steam Controller will only boot if the users turns on the controller with the chord, or plugs in via USB
[/td]

[/tr]

[tr]

[td] Exit Backpack Mode
[/td]
[td]Off
[/td]
[td]Steam+L4+L5+R4+R5
[/td]
[td]5s
[/td]
[td]Turn on the controller, if it is in backpack mode, it will exit backpack mode.
[/td]

[/tr]

[tr]

[td]Switch To Bluetooth Mode (Right Slot)
[/td]
[td]Off
[/td]
[td]Steam+B+R1
[/td]
[td]2s
[/td]
[td]Steam Controller will turn on and attempt to connect with the pairing information from the right slot. If no pairing information is available it will transition to pairing mode.
[/td]

[/tr]

[/td]

[/tr]
